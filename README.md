## 🎯 Project Overview
This project implements an **Artificial Neural Network (ANN)** using TensorFlow/Keras to predict **customer churn**.  
The model is trained on structured tabular data and deployed as an interactive web app using **Streamlit**.

---

## 🧠 Model Architecture
- **Input Layer** → Features from customer dataset
- **Hidden Layer 1** → 64 neurons, ReLU activation
- **Hidden Layer 2** → 32 neurons, ReLU activation
- **Output Layer** → 1 neuron, Sigmoid activation (binary classification)
